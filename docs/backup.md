# 备份与恢复

备份是一个版本化 JSON 信封（`.json.gz`），用**自然键**关联数据：友链以链接、分组以名称、文章与体检状态以所属友链的链接。因此同一个文件可以在任意实例上恢复，不需要 id 对齐，也不区分 Cloudflare 与 Docker。

## 备份包含什么

| 内容 | 是否默认包含 | 说明 |
| --- | --- | --- |
| 分组 | 是 | 名称、说明、排序 |
| 友链 | 是 | 全部字段：作者、趣称、标题、简介、链接、feed、图标、头像、架构、订阅日期、备注、是否入圈、显示状态、排序、添加时间 |
| 申请 | 是 | 含审核状态、审核备注与反链检测结果 |
| 设置 | 是 | 全部配置项（合并默认值后的生效值） |
| 文章 | 否 | 朋友圈抓取的产物，可以重新抓取 |
| 体检状态 | 否 | 可达性、延迟、反链等检测结果，会重新检测 |

不包含：`ADMIN_TOKEN`、`TURNSTILE_SECRET`、`GITHUB_PAT`、`WEBDAV_PASSWORD` 等密钥（它们在环境变量里），以及抓取轮次、上次备份时间这类运行时簿记。

## 手动备份与恢复

管理台「备份」页：

- **下载备份文件**：可选「包含文章与体检状态」，得到 `youlin-backup-YYYYMMDD-HHMMSS.json.gz`（UTC 时间）。
- **从文件恢复**：选择文件后会先解析并展示摘要（导出时间、条数、来源版本），确认后才会写入。
- **从 WebDAV 恢复**：列出云端备份，选一份直接恢复。

恢复是**覆盖式**的：先清空分组、友链、申请，再按备份写入，设置项按键覆盖。恢复前必须留存当前数据：

- 配置了 WebDAV：服务端自动上传一份 `pre-restore-*.json.gz`（含文章与体检状态），上传失败则中止恢复，不会动现有数据。
- 没配 WebDAV：要求 1 小时内在备份页下载过一份备份，服务端记录导出时间作为凭证——没下载过就恢复会被拒绝。

同一份文件重复恢复结果一致；中途失败时重试同一个文件即可（恢复从清空开始，不会叠加）。

备份里没有文章时，恢复会清空现有文章——它们会在后续抓取中重新补齐（这也是默认只备份核心数据仍然安全的原因）。

## WebDAV 自动备份

在「设置 → 备份」里填写：

| 配置 | 默认值 | 说明 |
| --- | --- | --- |
| 自动备份 | 关 | 开启后按周期上传 |
| 备份周期 | 每天 | 每小时 / 每天 / 每周（最小间隔） |
| 包含文章 | 关 | 打开后备份体积会明显变大 |
| 保留份数 | 7 | 只清理 `youlin-backup-*`；恢复前存档保留 30 天后自动清理 |
| WebDAV 地址 | 空 | 如 `https://dav.example.com/remote.php/dav/files/me/` |
| WebDAV 用户名 | 空 | Basic 认证用户名 |
| WebDAV 目录 | `youlin` | 相对于地址的子目录，不存在会自动创建 |

**密码只从密钥读取**：Cloudflare 用 `wrangler secret put WEBDAV_PASSWORD`（或控制台 Variables and Secrets），Docker 写进 `.env` 的 `WEBDAV_PASSWORD`。密码不写数据库、不进入任何备份文件。

自动备份的检查挂在每 5 分钟的定时任务上：抓取轮转结束后，如果距上次尝试已超过周期就上传一份；失败也会记录尝试时间，避免反复重试打爆 WebDAV。结果在备份页显示（时间、目标、大小或错误）。

支持的 WebDAV 服务：Nextcloud / ownCloud、坚果云、群晖 WebDAV Server、Alist 等。需要 HTTPS 时把地址写成 `https://`；自签证书无法通过校验，请给服务配好正规证书。

## 实例迁移

Cloudflare ↔ Docker 双向都可以：

1. 在旧实例导出备份（建议勾选「包含文章与体检状态」，这样朋友圈内容也一起搬走）。
2. 在新实例登录，备份页选择文件恢复。
3. 核对分组、友链、申请与设置；朋友圈文章在下次抓取后也会自动补齐。

Docker 实例的数据库在命名卷 `youlin_youlin-data`（容器内 `/data/youlin.db`）。如果只是搬机器，也可以停容器后直接拷贝这个文件，但跨版本升级时用应用内备份更稳妥。

## 已知限制

- **D1 单次调用的子请求上限**：Cloudflare 免费版对单次请求的子请求数有限制，特别大的备份（例如上万条申请）可能在恢复中途失败。恢复是幂等的，重试即可；更大的数据量建议在 Docker 实例上恢复。
- **恢复会覆盖设置**：包括 `site.url` 这类实例相关配置，恢复后按需在设置页改回。
- **不支持合并导入**：恢复是整体替换。若只想导入友链，用「导入」页的 JSON 批量导入（按链接去重、可重复执行）。
- **版本向后兼容**：更新版本导出的备份会被旧实例拒绝并提示升级；旧备份可以在新版本恢复。

## 本地调试

`wrangler dev` 只会把 `.dev.vars` 里、同时声明在 `wrangler.jsonc` 的 `secrets.required` 中的键注入到本地环境。WebDAV 密码是可选密钥，所以本地要显式传：

```bash
pnpm dev -- --var WEBDAV_PASSWORD:本地密码
```

本地也可以指向一个测试用 WebDAV（例如局域网里的 Alist），把设置页的地址改成 `http://` 地址即可。
