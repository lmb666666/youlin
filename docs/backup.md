# 备份与恢复 | Backup & Restore

备份是一个版本化 JSON 信封（`youlin.backup`，当前 `version=1`）。导出文件为 `.json.gz`；恢复时也接受未压缩的 `.json`（按 gzip 魔数识别，不看扩展名）。信封用**自然键**关联数据：分组以名称、友链以链接、文章与体检状态以所属友链的链接。因此恢复不依赖自增 id，也不依赖 SQLite 文件格式。

> 备份可以在相同或更新版本的应用上恢复。旧版本应用会拒绝更高版本的备份；当前只有一个备份格式版本，没有历史格式迁移器。

## 备份包含什么

| 内容 | 是否默认包含 | 说明 |
| --- | --- | --- |
| 分组 | 是 | 名称、说明、排序 |
| 友链 | 是 | 全部字段：作者、趣称、标题、简介、链接、feed、图标、头像、架构、订阅日期、备注、是否入圈、显示状态、排序、添加时间 |
| 申请 | 是 | 审核状态、审核备注、反链检测结果、联系方式与备注 |
| 设置 | 是 | 全部应用级配置的**生效值**（含环境变量覆盖后的结果） |
| 文章 | 否 | 朋友圈抓取产物，可以重新抓取 |
| 体检状态 | 否 | 与文章共用「包含文章」开关；会重新检测 |

不包含：

- `ADMIN_TOKEN`、`TURNSTILE_SECRET`、`GITHUB_PAT`、`WEBDAV_PASSWORD` 等部署级密钥。
- `PORT`、`HOST`、`DB_PATH`、`CRON_*`、`TRUST_PROXY`、`TZ` 等运行时环境变量。
- 轮转进度、清理水位、备份防抖、恢复凭证等 `internal.*` 运行时簿记。

备份文件是**明文** gzip JSON；申请人的联系方式与备注也在里面。请限制备份文件与 WebDAV 目录的访问权限。

## 手动备份与恢复

管理台「备份」页：

- **下载备份文件**：可选「包含文章与体检状态」，得到 `youlin-backup-YYYYMMDD-HHMMSS.json.gz`（UTC 时间）。
- **从文件恢复**：选择文件后先解析并展示摘要（导出时间、条数、来源版本），确认后才写入。
- **从 WebDAV 恢复**：列出云端备份，选一份直接恢复。

导出接口：`GET /api/admin/backup/export?articles=0|1`。压缩后上限 16 MB，解压后上限 64 MB；超过会返回 413。下载成功会记录时间并签发一个 **1 小时内有效**的恢复凭证（用于未配置 WebDAV 时的「先备份再恢复」约束）。

### 恢复语义

恢复是**覆盖式**的：

1. 清空分组、友链、文章、体检状态、申请表。
2. 按备份写入分组、友链、申请、文章/体检状态（如果包含）。
3. 设置项：先删除全部已知配置键，再写入备份中的键；备份里缺失的键会回退到代码默认值，不会保留旧值。
4. 清空与写入在同一个事务里；中途失败整体回滚。
5. 同一份文件可以重复恢复；每次恢复前都会重新执行留存检查。

恢复前的留存要求：

- **完整配置 WebDAV**（地址 + 用户名 + `WEBDAV_PASSWORD`）：服务端先自动上传一份 `pre-restore-*.json.gz`（包含文章与体检状态）；上传失败则中止恢复，不动现有数据。
- **未配置 WebDAV**：要求 1 小时内在备份页下载过当前数据的备份。下载凭证在成功恢复后失效；预览文件不会签发凭证。

注意：

- **预览不等于校验**：预览只解码并统计条数；引用完整性（分组/友链/文章关联）在真正恢复时才检查，所以预览成功仍可能恢复失败。
- **设置会被覆盖**：包括 `site.url`、`site.name` 等实例相关配置；恢复后按需在设置页改回。
- **环境变量覆盖不会消失**：`YOULIN_CONFIG_OVERRIDES` 里的值在恢复后仍然优先于设置表；备份里存的是导出时的生效值。
- 备份没有文章时，恢复会清空现有文章与体检状态；它们会在后续抓取/体检中重新补齐。
- 恢复不会触发重建，也不会重新抓取；需要时手动触发。

## WebDAV 自动备份

在「设置 → 备份」里配置：

| 配置 | 默认值 | 说明 |
| --- | --- | --- |
| 自动备份 `backup.enabled` | 关 | 开启后才会按周期上传；仅配置地址不会自动备份 |
| 备份周期 `backup.schedule` | 每天 | 每小时 / 每天 / 每周；这是**最小间隔** |
| 包含文章 `backup.includeArticles` | 关 | 打开后备份体积会明显变大，同时包含体检状态 |
| 保留份数 `backup.retain` | 7 | 只清理 `youlin-backup-*`；恢复前存档保留 30 天，在下次成功上传后机会性清理 |
| WebDAV 地址 `backup.webdavUrl` | 空 | 如 `https://dav.example.com/remote.php/dav/files/me/`；不能内嵌用户名/密码 |
| WebDAV 用户名 `backup.webdavUsername` | 空 | Basic 认证用户名 |
| WebDAV 目录 `backup.webdavPath` | `youlin` | 相对于地址的子目录；只会创建最后一级，父目录不存在会返回 409 |

密码只从环境变量 `WEBDAV_PASSWORD` 读取，不写数据库、不进入备份。修改密码后需要重建容器。

### 调度与重试

- 自动备份检查挂在调度器 tick 上，间隔由 `CRON_INTERVAL_SECONDS` 决定（默认 300 秒，最小 30 秒）。
- 只有 `backup.enabled=true` 且 WebDAV 配置完整（地址 + 用户名 + 密码）才会执行。
- 到达周期才上传；失败后 **10 分钟**重试，不必等满一个周期。
- 手动「立即上传」与恢复前存档不写调度时间戳，不打乱自动备份节奏。
- 单次 WebDAV 请求超时 30 秒；上传/下载上限 16 MB。

### 保留与清理

- 正常自动备份成功后，按 `backup.retain` 清理最旧的 `youlin-backup-*`。
- `pre-restore-*` 的 30 天 TTL 只在 prune 时检查；如果自动备份关闭且从不手动上传，恢复前存档不会被清理。
- 清理失败只记日志，不会把本次上传标记为失败。

### 支持的 WebDAV

Nextcloud / ownCloud、坚果云、群晖 WebDAV Server、Alist 等。建议使用 HTTPS；HTTP WebDAV 会让 Basic 凭据以明文传输。自签证书默认不被信任，请配置正规证书，或用 `NODE_EXTRA_CA_CERTS` 提供 CA。

## 实例迁移

### Docker → Docker

1. 旧实例导出备份（建议勾选「包含文章与体检状态」）。
2. 新实例登录，备份页选择文件恢复。
3. 核对分组、友链、申请与设置；朋友圈文章在下次抓取后也会自动补齐。

### 从 Workers 迁移

v0.3.0 是最后一个 Workers 版本：

1. 在旧 Workers 实例备份（建议包含文章与体检状态）。
2. 按[部署指南](deployment.md)启动 Docker 实例。
3. 在「备份」页恢复；备份信封 `version` 必须为 `1`。
4. 核对数据与设置。

### 直接拷贝数据库

跨版本升级优先用应用内备份。只搬机器且版本一致时，可以停容器后直接拷贝数据目录：

- Compose 卷名是 `<Compose 项目名>_youlin-data`，默认项目名才是 `youlin_youlin-data`。
- 数据目录包含 `youlin.db`、`youlin.db-wal`、`youlin.db-shm`；只拷 `.db` 可能丢 WAL 中的最新写入。
- 保持容器内 `node` 用户（通常 uid/gid 1000）的属主。
- 拷贝前 `docker compose stop`，不要 `kill -9`。

## 已知限制

| 限制 | 说明 |
| --- | --- |
| 恢复覆盖设置 | 实例相关配置会被备份值覆盖；环境变量覆盖仍优先生效 |
| 不支持合并导入 | 恢复是整体替换。只导入友链请用「友链 → 导入」弹窗 |
| 备份体积 | 压缩后 16 MB / 解压后 64 MB；数据多时关闭「包含文章」或清理已处理申请 |
| 版本兼容 | 只接受当前格式版本；旧实例会拒绝更新版本的备份 |
| 无加密 | 备份是明文 gzip；请自行加密或限制存储权限 |
| 预览不校验引用 | 预览成功不代表恢复一定成功 |

## 故障排查

| 现象 | 处理 |
| --- | --- |
| 401/403 | 检查 WebDAV 用户名与 `WEBDAV_PASSWORD`；修改密码后重建容器 |
| 404 | 检查 WebDAV 地址/目录；`webdavPath` 只创建最后一级，父目录需已存在 |
| 409 | 父目录不存在或远端拒绝 MKCOL；先手动创建父目录 |
| 超时 | 单请求 30 秒；检查网络与 WebDAV 服务 |
| 自签证书错误 | 使用正规证书，或通过 `NODE_EXTRA_CA_CERTS` 提供 CA |
| `prebackup_required` | 未完整配置 WebDAV，且 1 小时内未下载过当前备份；先下载备份 |
| `prebackup_failed` | 恢复前自动存档失败；检查 WebDAV 空间/权限，或先下载备份 |
| 413 | 备份超过 16 MB；关闭「包含文章」或清理已处理申请 |
| 版本不兼容 | 备份版本高于当前应用；升级应用后再恢复 |

## 本地调试

```bash
cp .env.example .env
# 编辑 .env：ADMIN_TOKEN、WEBDAV_PASSWORD
pnpm build       # 管理台静态资源
pnpm dev
```

本地也可以指向局域网 WebDAV（例如 Alist），把设置页地址改成 `http://` 地址；仅限可信网络，因为 Basic 凭据会明文传输。
